# Connect Byte + AWS 💜

📍 AWS Brazil  

📅 04th July 2026 

🏷️ Technology, Women in Tech, AWS, Kiro, Unity and Hardware

## About the event

An in-person event organized by Connect Byte in partnership with Amazon Web Services (AWS), focused exclusively on women in technology.

It was a great opportunity to meet an amazing community of women, exchange experiences, learn from each other and build new connections in technology.

This was also my first event focused exclusively on women in tech, which made the experience even more special.

## Main topics

- Women in technology;
- Amazon Web Services (AWS);
- Kiro;
- Unity;
- Hardware;
- Game development;
- Technology communities;
- Networking;
- Collaboration and knowledge sharing.

## Highlights

During the event, we developed a project using **Kiro and Unity**, creating a game controller using hardware.

One of the most exciting parts of the experience was building a **hardware circuit for the first time**.

It was a great opportunity to learn something new, work as a team and understand how software and hardware can come together to create interactive experiences.

A special thank you to [Dalila Brito](https://www.linkedin.com/in/dalilabritoo/) for helping me throughout this new experience! 🥹
